## 🚀 Featured Project

### 🏥 CareSync Health Network — Data Engineering Platform

A cloud-based data engineering project built to demonstrate an end-to-end data platform using Azure services and modern data engineering practices.

**Architecture & Key Highlights**

- 🔹 Built metadata-driven ingestion pipelines using Azure Data Factory.
- 🔹 Implemented a Bronze, Silver, and Gold medallion architecture in Databricks.
- 🔹 Developed full-load and incremental/merge-load processing patterns.
- 🔹 Used Azure SQL control and audit tables to track pipeline executions.
- 🔹 Integrated Azure Key Vault for secret management.
- 🔹 Connected GitHub for source control and CI/CD workflows.
- 🔹 Configured automated pipeline summary emails using Logic Apps.
- 🔹 Created a Databricks dashboard and a Genie agent for natural-language data exploration.
